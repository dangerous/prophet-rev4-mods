1. Your stock file

3. Install

  1. On the synth: Globals → MIDI SysEx = USB.
  2. Connect by USB and send the file with a SysEx utility (SysEx Librarian on macOS, MIDI‑OX on Windows, SendMIDI anywhere) — exactly as you would an official OS update.
  3. The display counts to 100 while the OS is written; the synth restarts into the new OS. Tap A440: the LED lights and the arpeggiator is on.

Not affiliated with Sequential. This is a hobby project that modifies the instrument's firmware. Installing a modified OS is at your own risk and may void your warranty. Holding A440 while powering on bypasses the patch for that session, and the official 2.1.0 file re‑installs the stock OS at any time. If an OS update ever fails to boot, recovery is through bootloader mode, which needs a 5‑pin DIN MIDI connection — have one available before you start.

Manual, controls and source: github.com/dangerous/prophet-rev4-mods. Only the project's own code is published; Sequential's OS files are not redistributed.
